# Lichenic Web

Work in progress. This branch uses **Svelte**.

### Usage

Make sure to install pnpm, then install dependencies:

```bash
pnpm i
```

Then start the dev server:

```bash
pnpm dev
```

This will watch the project directory and restart as necessary.
